## Research task

Build a Philippine Opportunity Source Map (not individual opportunities yet)

I curate a newsletter at **stimmie.dev/opportunities** for students and early-career builders in the **Philippines**. Before finding specific hackathons/internships/scholarships, I need a **comprehensive source map**: where opportunities are *published first*, how to monitor each source, and what types each source is best for.

**Do NOT list individual opportunities in this report.** Only map sources, search tactics, and monitoring workflows.

### Categories to cover

1. **Hackathons & buildathons** — Devpost, Devfolio, DoraHacks, lablab.ai, HackerEarth, MLH, GitHub hackathon lists, corporate build sprints
2. **Internships & fellowships** — Prosple, Intern.ph, Kalibrr, JobStreet, LinkedIn, company career pages, Outreachy, GSOC, ADB/UN/ASEAN portals
3. **Scholarships & grants** — CHED, DOST, GSIS, TESDA, DICT, corporate (Grab, Globe), Chevening, ADB-Japan
4. **Events & conferences** — Meetup, Luma, Eventbrite, Friends of Figma, UXPH, DEVCON, campus org FB pages
5. **Certificates & courses** — Coursera/DICT, Grow with Google, AWS Educate/Scholars, ITU Academy, UPOU MODeL, Cisco NetAcad
6. **Startup / builder / AI elite** — Y Combinator events, a16z SPEEDRUN, HF hackathons, NVIDIA Inception, startup PH (Geeks on a Beach, IGNITE)
7. **Social & community** — Reddit subs, Facebook groups, Discord servers (Codédex, CSCareers, PH tech), X/Twitter lists
8. **GitHub & newsletters** — SimplifyJobs, vanshb03, opportunity Substack/Medium digests

### For EACH source, document

| Field | What to include |
| ----- | --------------- |
| **name** | Platform or community |
| **url** | Homepage or best entry point |
| **best_for** | hackathon / internship / scholarship / event / cert / program |
| **ph_relevance** | High / Medium / Low + why |
| **freshness** | How often updated; RSS/API/newsletter available? |
| **search_tactics** | Exact URLs, filters, keywords (e.g. Devpost `?challenge_type[]=online&...`) |
| **noise_level** | Low / Medium / High (spam, reposts, expired listings) |
| **trust_level** | Whether official links are usually one click away |
| **monitoring_cadence** | daily / weekly / monthly check |
| **niche_communities** | Related Discords, FB groups, subreddits |

### Must explicitly evaluate (don't skip)

- **Devpost** vs **Devfolio** — overlap, PH-specific filters, which has more PH-accessible online events
- **Codédex** (codedex.io + Discord) — separate from Codecademy
- **GitHub internship repos** — which are maintained in 2026; PH/remote filter strategy
- **LinkedIn** — boolean search templates for PH internships (not job search result pages as final URLs)
- **Reddit** — which subs surface real opportunities vs memes
- **Facebook** — DEVCON PH, campus CS groups, "hiring intern PH", hackathon announcement patterns
- **YC / Luma** — events.ycombinator.com, local SF/hybrid events open to intl applicants
- **Prosple vs Indeed vs Kalibrr** — when to use each; how to extract employer-site links
- **Government** — official domains only (ched.gov.ph, dost.gov.ph, dict.gov.ph, bpms.ched.gov.ph) vs aggregator blogs to avoid

### Output format

1. **Executive summary** — top 15 highest-ROI sources for a PH student curator
2. **Source map table** — all sources sorted by `ph_relevance` then `trust_level`
3. **Weekly monitoring playbook** — Mon–Sun checklist: what to check each day (15 min/day max)
4. **Source-specific search recipes** — copy-paste URLs and queries per platform
5. **Anti-patterns** — sources to deprioritize (expired aggregators, Scribd reposts, Indeed search URLs)
6. **Gaps** — opportunity types with weak source coverage in PH (e.g. humanities, pure arts)
